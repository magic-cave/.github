# Magic Cave

Small tools that run on your device, and the open source behind them.

- **[lunisolar-picker](https://github.com/magic-cave/lunisolar-picker)** — React date pickers with Korean lunar (음력) input. [Docs](https://lunisolar.magic-cave.com)
- **[Statement CSV](https://statement-csv.magic-cave.com)** — Turn bank statement PDFs into CSV on your device.
- **[Local Redact](https://local-redact.magic-cave.com)** — Find and redact PDF content in your browser.
